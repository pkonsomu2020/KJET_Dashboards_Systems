# Terminology

Every label, heading, tooltip, PDF and assistant answer uses the wording of the *KJET Business Development Services and Co-Investment Grant Operations Manual* (July 2026, revised). When adding text, use these terms.

| Use | Not | Manual reference |
|---|---|---|
| Co-investment grant, matching grant | KJET grant, grant-ready | 5.3 |
| **Matching grant requested** (at most 50% of the project cost) | Grant requested, KJET grant | Annex V 3.1, 5.2 |
| **Cluster cash contribution** (at least 50%, cash only) | Cluster contribution, cash match, cost remainder | 5.1, 5.3, Annex V 5.2 |
| **Total project cost** (machinery and equipment plus bundled services) | Eligible project cost | Annex V 3.1 |
| **Window 1 (Growth Window)**, up to US$40,000 (about KES 5M) | Category 1 | 5.3 |
| **Window 2 (Transformational Window)**, up to US$250,000 (about KES 32M) | Category 2 | 5.3 |
| Sub-project, Co-investment Application, applicant, beneficiary, MSME cluster | project, proposal | 5.1, 5.4 |
| Tier 1 clusters | | 5.1 |
| Persons with disabilities; youth (under 35); women; men | PWD, people with disability | Annex V 1.2 |
| Jobs and income: total jobs (full-time equivalents), of which women, youth under 35, persons with disabilities; today (baseline), after investment (Year 1), (Year 3) | Employment outlook, projected jobs | Annex V 4.3 |
| Average monthly income per cluster member | Avg income | Annex V 4.3 |
| Authorized Representative, Project Manager | | Annex V 1.3 |
| Selection Firm; Independent Evaluation Technical Panel (IETP); Project Implementation Team (PIT) | | 5.4 |

Wording that comes from the evaluation workbook rather than the manual (the screening results such as "FOLLOW-UP: data error", the E1 to E10 test names and the criterion names C1 to C6) is shown as the evaluators wrote it.
